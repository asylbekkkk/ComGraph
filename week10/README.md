# 10-апта: толық еркін камера

Тінтуірмен бағытты өзгерту (yaw/pitch) және дөңгелекпен көру бұрышын (fov) басқару. Негізі 9-аптадағы камера (`camPos`, `camFront`, `camUp`, WASD, delta time).

## Басқару

- Тінтуір: айналу, дөңгелек: zoom
- W/A/S/D: жүру, Space/Left Shift: жоғары/төмен, Left Ctrl: жүгіру
- I: Invert Y, P: камера күйін терминалға шығару, R: бастапқы күйге қайту, ESC: шығу

## Таңдалған sensitivity

Таңдалған мән: **[0.03 / 0.1 / 0.5 ішінен өзің таңда]**. Себебі: [бір сөйлеммен жаз, мысалы: бір толық айналым үшін тінтуірді неше рет көтеріп қою керек болды].

## 1-тапсырма: pitch шектеуінсіз

Шектеуді алып тастағанда экран [өзің көргеніңді жаз: ағарды / бір түсті болды / төңкеріліп кетті] болды. Бұзылған pitch мәні: **[терминалдан көрген мәнді жаз]**.

Себебі: `pitch = 90°` кезінде `cos(90°) = 0`, сондықтан `dir.x` пен `dir.z` нөлге айналады да, `camFront = (0, 1, 0)` болады, яғни `camUp`-пен бағыты сәйкес келеді. `lookAt` ішінде `cross(camFront, camUp)` нөлдік вектор береді, нөлді нормалау (`0/0`) NaN береді, view матрицасы NaN-мен толады да, сурет бұзылады. Нақты санмен `float` дәлдігіне байланысты бұзылу 90°-қа дәл жетпей, сәл ерте немесе кеш көрінуі мүмкін.

## 5-тапсырма: үлкен fov неге суретті «созады»

Бұл қате емес, перспективалық проекцияның қалыпты қасиеті. Проекция матрицасында `f = 1 / tan(fov/2)` бар. fov үлкейгенде камера кеңірек бұрышты қамтиды да, сол кең бұрыш бірдей экранға сыйғызылады, сондықтан экран шетіндегі нысандар центрдегіге қарағанда көбірек үлкейтіліп, созылған болып көрінеді (кең бұрышты объектив эффектісі).
